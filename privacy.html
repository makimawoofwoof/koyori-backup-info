Koyori Backups

Privacy and data handling

Updated 6 October 2026.

Koyori Backups is a personal utility operated by makimawoofwoof to preserve copies of the operator's GitHub repositories. It is not offered as a public service.

Google data and permissions

The app requests the Google Drive drive.file permission. It uses this permission to create, read, update and delete its encrypted backup repository. It also checks available Google storage before uploading. It does not request Gmail, Photos, contacts or unrestricted Drive access.

Use and storage

Repository content and associated exported metadata are encrypted with Restic before being sent to the operator's Google Drive. The encryption password and Google authorization credentials are kept in access-restricted files on the operator's server. The operator is responsible for preserving the recovery password separately. Authorization credentials are used only to operate this backup connection.

Google data obtained by this utility is used only for backup, restoration, integrity checks and storage management. It is not sold, used for advertising, shared with data brokers or used to train artificial intelligence models. Google processes storage and authorization as the service provider. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and control

Cloud retention selects the latest two snapshots, seven daily snapshots, four weekly snapshots and three monthly snapshots; these selections overlap. Cleanup permanently removes data that no retained snapshot requires. Unchanged content is reused between snapshots.

The operator can stop backup jobs, revoke the app's authorization in Google Account settings, and delete the backup repository from Drive. Revoking access stops future access but does not itself delete existing backups. Local server copies are managed separately.

This website

This static information site has no application login, forms, analytics scripts or advertising. Its hosting provider may process ordinary web request information under its own policies.

Contact
